T40 雷达控制台 0.5.0 · Windows x64 测试版

支持范围
Windows 10/11 x64；USBWLAN 0CF3:1022（AR6004 hw3.0）；PCAN 兼容 USB-CAN 0C72:000C。不是任意品牌网卡或 CAN 适配器的通用驱动。雷达需要独立供电，USB 设备归 Windows 使用。

安装将执行
1. 安装完整运行环境，无需另装 Python、VMware、Linux 或依赖库。
2. 安装 PCAN USB 驱动及 TAP 虚拟网卡驱动；创建名为 T40 Radar 的专用网卡。
3. 为 USBWLAN 安装 WinUSB。该硬件将由雷达软件使用，不作为普通 Wi-Fi 网卡使用。使用当前已验证的 libwdi 设备目录签名证书，导入本机“受信任的根证书颁发机构”和“受信任的发布者”；证书仅随本设备驱动目录分发，不包含私钥。不关闭驱动签名验证。
4. 专用网卡使用 192.168.8.1/32，并添加到雷达 192.168.8.2/32 的路由；仅为本程序与该雷达的 UDP 通信添加防火墙入站规则。不更改默认网关、DNS 或路由器设置。若地址被其他网卡占用，报告冲突并停止配置。

使用
安装 → 连接 USBWLAN 与 USB-CAN、给雷达供电 → 双击桌面“ T40 雷达控制台 ” → 手动启动旋转。调速前先停止；关闭窗口时程序发送停转指令并退出无线接收进程。
设备故障时先查看面板提示。界面不把没有数据的旧点云显示成实时点云。日志保存在 %LOCALAPPDATA%\T40Radar；安装日志保存在 C:\ProgramData\T40Radar。

360° 扇区数据源
通过雷达现有 SSH 服务只读完整扇区内存快照，不修改雷达固件或内存。首张快照只作更新基准，停转或未更新时不显示为实时点。默认显示方位—斜距图，角度零位和比例待实物校准；高度尚未可靠解码，因此三维视图请切换“避障候选”。360 个记录槽全部读取不代表每个方向都有回波，空白不等于无障碍。切换数据源在右侧“数据与密度”中。

点云工作台
默认显示全部图层，自动扩展视野，不过滤固定高度、不抽样单帧有效点。默认累积最近 5 秒，可切换最新帧、2 秒或 10 秒；历史缓存最多 250,000 点，超出容量按时间淘汰并显示计数。大量点绘图速度会降低。
3D / 俯视 / 侧视；左键旋转、中键平移、滚轮缩放；“显示全部”恢复完整视野。高度视觉比例默认 2 倍，可改为 1 倍真实比例或 4 倍；坐标数值始终为实测米数。局部格网轮廓为回波占据范围估计，不代表真实物体表面；实际格距在图上标明，原始点独立完整绘制。移动雷达或观察运动目标时建议选择最新帧，避免累积残影。
冻结观察不停止接收或电机。导出 CSV 包含当前数据窗全部有效点，包括关闭图层的点。F11 切换全屏，侧栏可收起，底部保留电机控制。

卸载
从 Windows 应用列表卸载。删除本软件创建的专用网卡与防火墙规则；保留数据目录、共享 USB 驱动及设备目录签名证书，避免影响其他程序。
