# T40 实时点云网页伴侣

保持现有 T40 雷达控制台运行，然后双击 `start-web-radar.cmd`。网页只读，不发送电机、转速或设备配置命令。

- 雷达停止时显示等待状态，不显示模拟点。
- 实际转速达到 150 RPM 后，网页开始读取完整扇区回波。
- 原软件的数据源应保持“避障候选”。若原软件切换到“360° 扇区”，网页会自动暂停，避免两边同时读取。
- 高度按当前扇区解码采用的投影公式计算：`Z = sin(俯仰角) × 斜距`。
- 网页支持相对雷达、雷达测高、手动安装高度和当前地面归零。俯仰字段无效的点仍可显示，但不会参与地面校准。

字段解释与实际标定的区别见 [数据说明](../docs/DATA.md)。
